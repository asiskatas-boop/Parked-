# Parked! 0.2.2

- Added a dedicated **Refuel** button on the Fuel screen. Refuels remain separate from routine fuel-level logs.
- Replaced the custom vertical fuel capsule with a native Material slider and clear **1/4, 1/2, 3/4** markers.
- Fixed **Match my car** colour persistence by normalizing legacy colour names and invalid old `Match my car` preference values to supported car colours.
- Fuel-level logs can be deleted individually with confirmation; deletion updates persisted history.
- Bumped Android build to version code 4 / version 0.2.2 so this build is easy to distinguish from 0.2.1.
